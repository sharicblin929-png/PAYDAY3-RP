# PAYDAY 3 — THE NEW BLOOD | текстовая RPG

**Статус: ПОДГОТОВКА. Пролог НЕ начат.** Дата основания: 2026-11-08.  
**Начать здесь:** [00_SYSTEM/START_HERE.md](00_SYSTEM/START_HERE.md) и [00_SYSTEM/CURRENT.md](00_SYSTEM/CURRENT.md). Проект не зависит от архивов других RPG.

Самостоятельная RPG по PAYDAY 3. Дмитрий Орлов, **Circle**, 22-летний русский грабитель-одиночка и технический самоучка. Старая интернет-знакомая Джой (PAYDAY Gang) рекомендует его команде. Знакомство НЕ означает близкой дружбы или автоматического принятия. Стартуем у начала истории PAYDAY 3 (ориентировочно 2023; точная дата ещё не утверждена).

**Жанр:** криминальный экшен, стелс, живая команда, повседневность и реалистичные последствия с юмором PAYDAY. Основная деятельность — ограбления **на местах**, не удалённая офисная работа.

## Операционная логика
- Новая RPG полностью самостоятельна: прежние RPG-репозитории НЕ читать. Их технические и игровые принципы уже отражены здесь; чужие сюжетные состояния не переносить.
- Не создавать параллельные CURRENT/LATEST/START_HERE. Историю — в неизменяемую хронику, динамику — в CURRENT/целевые реестры.
- Перед **каждым** ограблением на брифинге создать **подробные схемы**: улица/квартал, территории/заинтересовавшие объекты, **каждый этаж отдельно**, легенда и описание. Карты могут отличаться от игровых; источники сведений и неизвестные участки обозначаются.
- Игровая преступная деятельность — художественный контекст; настоящая техническая практика — только на собственных или специально разрешённых учебных системах.
- **Маска Circle: [НЕ ОПРЕДЕЛЕНА]** — не заполнять без команды игрока.
- Репозиторий **публичный**: не помещать секреты, токены, личные данные, реальные чувствительные схемы/адреса и приватные лабораторные логи.
