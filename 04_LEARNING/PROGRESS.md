# PROGRESS — реальный учебный прогресс на входе в PAYDAY

**Самодостаточный перенос 2026-11-08.** Старые RPG читать не требуется. Это **OOC-навыки пользователя**, а не автоматически полученные Circle полномочия в игре.

| Модуль | Честный статус | Подтверждённые действия |
|---|---|---|
| Kali/OpenVPN | есть практика | Терминал, доступ к официальной THM Lab Machine, работа с VPN и исправление двойного туннеля |
| Nmap / Further Nmap | **практика выполнена, весь курс НЕ подтверждён завершённым** | `-sT`, `-Pn`, `-sV`, `-p`, `--top-ports`, `-oN`; TCP 21/53/80/135/3389, UDP53, HTTP IIS, DNS; `TRACE` был объявлен, не выполнялся |
| SecLists / HTTP / Burp | освоены базовые практики | Словари, исходник/комментарии/robots/sitemap, GET/POST, статусы/заголовки, Network/Proxy/History |
| THM Content Discovery | **полностью завершена** | Gobuster path/DNS, X-Flag, development.log, /assets/, найденные учебные разделы; ручная интерпретация |
| THM ffuf / DVWA | **практика и материал пройдены; официальный полный зачёт всех Task не доказан** | `FUZZ`, пути /login.php /README.md /robots.txt /php.ini, 403 на .htaccess/.htpasswd; фильтры status/size/words/lines, GET/POST, `Host: FUZZ` |
| THM Linux Privilege Escalation: Enumeration | **начата, завершение не подтверждено** | `sudo -l`: `john` может без пароля `/usr/bin/nmap`, но файл не найден; интерфейс ens5, DNS на 127.0.0.53/.54:53, ssh :::22; найдены 2 учебных флага. Это **не подтверждённый root** |
| Python | начальное знакомство | Hello World известен, малый опыт; не начинать курс с нуля, но не считать специалистом |

**Не путать:** выполненное учебное упражнение ≠ полностью закрытая комната; открытый порт ≠ доступ администратора; найденный файл ≠ успешное повышение привилегий.

**Ближайший практический шаг:** продолжить THM Linux Enumeration по оставшемуся Task; дальнейшая последовательность — [ROADMAP](ROADMAP.md), ссылки — [RESOURCE_DIRECTORY](RESOURCE_DIRECTORY.md). Все динамические IP берутся из текущего интерфейса стенда, не из старой истории.

**Новые записи:** `дата | платформа/разрешённая лаборатория | задача | что пользователь сам выполнил | проверенный результат | что не удалось | следующий шаг`. Не публиковать действительные пароли, ключи, приватные IP/логи в публичном репозитории.
