# Реально подтверждённый технический прогресс игрока

**Источник переноса:** рабочие подтверждения отдельного чата и ранее существовавшие заметки CYBERPUNK2077-RP. Не путать с автоматически освоенным внутри PAYDAY — знания Circle в IC развиваются согласованно со сценами.

## Подтверждено до начала PAYDAY
| Модуль | Статус | Доказанные навыки |
|---|---|---|
| Content Discovery (THM) | выполнено | исходник HTML, HTTP-заголовки, robots.txt/sitemap, поиск скрытых ресурсов и доменных записей |
| Further Nmap | выполнено | сканирование без ICMP (-Pn), сервисы TCP/UDP, IIS, методы HTTP, осторожная интерпретация находок |
| ffuf / DVWA | выполнено | поиск путей, параметры GET/POST, фильтры -fs/-fl/-fw, vhost Host: FUZZ, различие 403/404/ложных совпадений |
| Linux Privilege Escalation: Enumeration (THM) | начато, НЕ завершено | sudo -l, интерфейс ens5, сетевые службы/netstat, права и обнаружение учебных файлов; флаги найдены, но прохождение не объявлено оконченным |
| Python | базовое знакомство | `Hello World` и некоторые простые концепции известны, **не считать продвинутым программистом**, не начинать уроки с азов без реальной потребности |

**Примечание:** обучение «пройдено» ≠ герой автоматически способен применить любой продвинутый приём или сконструировать сложное устройство. Неподтверждённое не засчитывать. Старые THM IP динамические; не переносить их как постоянные актуальные цели.
