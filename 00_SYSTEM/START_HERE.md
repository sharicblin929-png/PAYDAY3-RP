# START_HERE — три режима PAYDAY3-RP

**Единственная каноническая база:** этот GitHub `main`. [Notion](NOTION_ARCHIVE.md) — лёгкое оперативное зеркало, не замена. **Старые RPG-репозитории не нужны.**

## RPG — первый запуск
1. Прочитать [CURRENT](CURRENT.md), [RULES](RULES.md) и [RUNBOOK](RUNBOOK.md) **один раз при входе в чат**. При необходимости первой сцены прочитать [Circle](../02_CHARACTERS/CIRCLE.md).
2. **Каждый дальнейший пост:** короткий [CURRENT](CURRENT.md) + [актуальный KNOWLEDGE_SNAPSHOT](../01_WORLD/NPC_KNOWLEDGE_LEDGER.md) (для знаний участников) + последний завершённый GM. Остальные файлы — только по месту/действию по [RUNBOOK](RUNBOOK.md). **Не читать исторический knowledge archive и старые аудиты в обычном ходе.**
3. **Сюжет уже начат.** Номер последнего завершённого GM, текущие обстоятельства и следующий ход определяются **только [CURRENT](CURRENT.md)**. **Не запускать пролог повторно**. Игрок единолично выбирает действия Circle; Маска **«Клоунатор» / Clowninator** подтверждена как личная маска Circle, не менять её дизайн или доступность по датам реальных DLC.

**Команда для нового RPG-чата:** «Продолжай PAYDAY 3 RPG с последнего подтверждённого GM в GitHub; прочитай START_HERE, CURRENT, KNOWLEDGE_SNAPSHOT, RULES, RUNBOOK и последний GM; не начинай пролог заново и не повторяй уже раскрытые факты».

## МАШИНЫ — учёба
Прочитать [PROGRESS](../04_LEARNING/PROGRESS.md), [PROGRAM](../04_LEARNING/PROGRAM.md) и [ROADMAP](../04_LEARNING/ROADMAP.md), ссылочный [RESOURCE_DIRECTORY](../04_LEARNING/RESOURCE_DIRECTORY.md) только по теме. Реальная практика — на своих/разрешённых стендах, без GM, временных сдвигов и записи сюжетных денег. Когда новая техническая задача возникает **на ограблении**, RPG предлагает **2–3 учебных направления**, затем выбранное направление можно разобрать здесь; это не ограничивает свободные решения Circle.

**Команда:** «Техническая практика PAYDAY: продолжим по PROGRESS и ROADMAP; без GM и без коммитов».

## ТЕХНИКА И ПРАВКИ
Прочитать CURRENT, правила и только затронутые реестры; исправить адресно, проверить GitHub-коммит и нужные страницы Notion, не начинать игровую сцену.

**Команда:** «Аудит/правки PAYDAY3-RP: сверить CURRENT, RULES и затронутые документы, изменить и перепроверить. Без игрового хода».

**Приоритет:** последнее прямое решение игрока > завершённая сцена (источник-доказательство GM) > компактное CURRENT (активное состояние) + KNOWLEDGE_SNAPSHOT (знания и свидетели) + профильные реестры > RULES > исторические аудиты. Прерывание генерации **не создаёт канон**.
