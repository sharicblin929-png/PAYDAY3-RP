# START HERE — автономный запуск PAYDAY3-RP

**Единственный источник истины для новой RPG:** этот GitHub-репозиторий, ветка main. Репозитории других игр открывать НЕ нужно. Notion — необязательная вторичная копия, не обязательное условие работы.

## Чат RPG
Прочитать [CURRENT](CURRENT.md), [RULES](RULES.md), [RUNBOOK](RUNBOOK.md), [Circle](../02_CHARACTERS/CIRCLE.md), [NPC knowledge](../01_WORLD/NPC_KNOWLEDGE_LEDGER.md), а после начала игры — последний завершённый GM и связанные с действием реестры. Пролог ещё НЕ сыгран — старт только после команды пользователя. Не писать за Circle.
Для нового ограбления предварительно составить **полный визуальный пакет карт** и текстовое описание по [стандарту](../03_HEISTS/BRIEFING_MAP_STANDARD.md): схема улицы и территории, планы интересующих объектов, **каждый известный этаж отдельно**. После поста адресно записать GM/CURRENT, проверить GitHub. Сейв раз в 20 GM и после важного события.

**Сообщение для нового RPG-чата:** «Работаем только с sharicblin929-png/PAYDAY3-RP. Прочитай 00_SYSTEM/START_HERE.md, CURRENT, RULES и RUNBOOK. Не привлекай архивы других RPG. Я отдельно дам команду начать».
