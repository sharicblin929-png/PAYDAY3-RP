# EMERGENCY_FALLBACK — Notion только в крайнем случае

**Решение пользователя от 2026-11-09.** GitHub `sharicblin929-png/PAYDAY3-RP`, ветка `main` — **единственная нормальная база памяти, хроники и сейвов**. Notion — **финальный аварийный резерв** на случай, когда GitHub **действительно недоступен для записи**. Не планировать периодическую Notion-синхронизацию и не читать Notion перед обычными GM. Контрольные сейвы — в GitHub [07_SAVES](../07_SAVES/README.md) после каждых 50 GM и крупных событий.

## Когда использовать аварийный Notion
1. Попытка сохранить GitHub не удалась; проверить результат/текущее состояние, повторить осторожно (не создавать дубли). **Только подтверждённая невозможность GitHub-записи**, а не предположение «будет медленно».
2. Если **важно срочно сохранить** факты/последнюю сцену и Notion доступен, записать **одну минимальную аварийную запись** с пометкой `EMERGENCY / PENDING_GITHUB`: время, последний проверенный GitHub HEAD и GM-номер, точно завершённые слова/события, изменения CURRENT и реестров, что осталось незаписанным, ссылки на исходные посты.
3. **Не считать аварийную запись новым каноническим GitHub-коммитом** и не утверждать, что штатное сохранение успешно; явно сообщить пользователю, что сведения временно в Notion.
4. Когда GitHub вновь доступен, **сначала** прочитать свежий HEAD/CURRENT, сопоставить с аварийной записью, **перенести только действительно отсутствующее** одним корректным GitHub-коммитом, проверить; после этого пометить резервную запись `MIGRATED`. Не применять вслепую поверх изменившегося канона.
5. Если недоступны оба сервиса, не обещать фоновой записи и не сообщать об успешном сейве; изложить точный статус и зафиксировать факты в чате до восстановления возможности сохранять.

**Разовая проверка перед отключением Notion:** просмотрены корневой хаб, CURRENT, RULES, Circle, WORLD/NPC, HEISTS, LEARNING, ECONOMY, HISTORY, AUDIT и аварийная копия SAVE_AFTER_GM-0020. Подтверждённых **уникальных новых игровых фактов**, отсутствующих в GitHub на GM-0023, не выявлено. Поправка **FSA-12G**, сведения Circle о WoW/Call of Duty, последний GM-0023, реестры и учебный прогресс уже представлены в GitHub. Поэтому разовая миграция не требуется.
