# Аудит автономности — 2026-11-08

**Задача:** играть и обслуживать PAYDAY3-RP **без обращения к репозиториям Cyberpunk и STALKER**. В прошлом они использовались лишь для проектирования архитектуры; это **не** текущие источники.

## Найденные дефекты первой редакции и исправления
1. Прямая ссылка из учебной программы на приватный каталог другой RPG — **удалена**. Локальный [RESOURCE_DIRECTORY](../04_LEARNING/RESOURCE_DIRECTORY.md) содержит нужные учебные площадки, описания и правила выбора.
2. Первый PROGRESS ошибочно заявлял полное завершение Nmap/ffuf. Исправлен: завершённой подтверждена Content Discovery; Nmap — практика без полного зачёта; ffuf — материал/практика без доказанного официального зачёта; Linux Enumeration — начата.
3. Не хватало подробного автономного учебного маршрута — [ROADMAP](../04_LEARNING/ROADMAP.md).
4. Не хватало инструкции ввода любого из трёх чатов — [START_HERE](../00_SYSTEM/START_HERE.md).
5. Не хватало локального реестра знаний NPC — [NPC_KNOWLEDGE_LEDGER](../01_WORLD/NPC_KNOWLEDGE_LEDGER.md).
6. Ссылки шаблона брифинга на несуществующие будущие карты изменены на буквальные имена-заготовки; реальные карты создаются **при брифинге**, а не фиктивно заранее.

## Критерии
- [x] Все действующие нормы, текущее состояние, досье Circle, банда, убежище и знание NPC — **внутри PAYDAY**.
- [x] Реальный учебный прогресс, программа, путь и каталог ресурсов — **внутри PAYDAY**.
- [x] Ограбления, процедура брифинга, визуальные схемы, бюджет, хроника и сейвы — **внутри PAYDAY**.
- [x] Новые чаты получают инструкцию для работы **исключительно из PAYDAY3-RP**.
- [x] Notion необязателен; отдельный старый Rollbook не требуется.
- [x] Пролог не начат; денег не начислено; **маска Circle — [ПУСТО]**.

## Что автономность НЕ означает
Реальные разрешённые лаборатории (TryHackMe и т.п.) и проверка актуального официального лора требуют внешних тематических источников. Это **не** другие RPG-репозитории. Данные динамической лабораторной сессии пользователь приносит в чат; нельзя вечно хранить её случайный IP как действующий. Старые RPG-истории и их герои не переносятся — они для PAYDAY не нужны.

## Повторная проверка
При каждом структурном изменении проверять существование всех локальных ссылок, отсутствие ссылок на старые приватные RPG, отсутствие второго CURRENT, реальное состояние хронологии и пробелов. Исторический первый аудит 2026-11-08 сохраняется как свидетельство первоначальной версии, а не актуальный операционный регламент.
