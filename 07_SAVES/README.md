# Полные переносимые сейвы

**Пока нет ни одного сейва: игра не началась.**

Создавать после каждых **20 завершённых** GM-постов и после ключевых событий, не дублируя предыдущие сейвы внутрь новых. Пример: `SAVE_AFTER_GM-0020.md`.

Каждый сейв самодостаточен в отношении **текущего** игрового состояния:
- номер завершённого GM, точные дата/время/место и граница сцены;
- последняя подтверждённая речь/действие Circle и нерешённые выборы;
- присутствующие и доступные знания NPC (не телепатия);
- стадия ограбления/ссылки на карты и известные изменения;
- физическое состояние, предметы, боезапас, деньги и доли;
- открытые сюжетные линии, репутация, незавершённые дела;
- отдельный короткий статус учебных результатов (не архив реальных логов);
- источники: CURRENT, последние GM, нужные реестры.

Сохранение записывается **в GitHub** и перепроверяется чтением. Вторичная копия Notion теперь предусмотрена в самостоятельном [PAYDAY Notion-архиве](../00_SYSTEM/NOTION_ARCHIVE.md): дочерние страницы сейвов под «07 — Хроника, сейвы», после подтверждённой записи GitHub. Старые сейвы не редактируются задним числом.
